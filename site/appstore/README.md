# App Store 스크린샷

실기기에서 찍은 것이다(아이폰 · 1179×2556). **`dist/` 는 gitignore 라** 거기 두면
빌드를 지우는 순간 같이 사라진다 — 다시 찍으려면 그때의 사무실이 필요하므로 여기 둔다.

    01-office   사무실 · 고양이 넷
    02-inbox    결재함 — 할 일을 올리는 자리
    03-staff    직원 · 사원증
    04-parcel   상자를 뜯는 컷신
    05-intro    오프닝 — "눈을 떴을 때 나는 이미 채용되어 있었다"
    06-flyer    오프닝 — 전단지

업로드 순서가 곧 파일 이름 순서다. 원고는 [../APPSTORE.md](../APPSTORE.md).

새로 찍으려면 `node tools/capture-ios.js` (폰 배포본을 띄워 놓고). 다만 그건
**새 저장**으로 찍으므로 화면이 비어 보인다 — 진행된 사무실이 필요하다.
