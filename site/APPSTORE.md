# App Privacy (데이터 수집 신고)

**분석·추적 SDK가 하나도 없다**(2026-09-04 확인). 나가는 곳은 셋뿐이다:
Supabase(계정·저장·친구) · `copycat.sarl`(정책 문서) · jsDelivr(라이브러리).

## 추적(Tracking)

```
아니오 — 다른 회사의 앱이나 웹사이트를 가로질러 추적하지 않습니다
```

ATT 동의창이 필요 없다.

## 수집하는 데이터

| 분류 | 항목 | 목적 | 신원 연결 | 추적 |
|---|---|---|---|---|
| 연락처 정보 | 이메일 주소 | 앱 기능 | 예 | 아니오 |
| 사용자 콘텐츠 | 기타 사용자 콘텐츠 (할 일 목록·사무실) | 앱 기능 | 예 | 아니오 |
| 식별자 | 사용자 ID | 앱 기능 | 예 | 아니오 |
| 구매 | 구매 내역 | 앱 기능 | 예 | 아니오 |

**이메일**은 구글이나 메일로 로그인한 사람만 해당한다. 로그인 없이도 게임은 다 돌고,
그때는 익명 계정 id 만 있다.

**할 일 목록**을 「사용자 콘텐츠」로 신고하는 이유: 저장에 실려 서버로 올라가고,
지점 코드를 주고받은 친구에게는 **그날 것만** 보인다(`FRIENDS.mine`). 감출 일이 아니라
정확히 적는다.

수집하지 않는 것: 위치 · 연락처 · 사진 · 건강 · 금융 · 검색 기록 · 광고 식별자 ·
진단 정보. 크래시 리포트도 안 받는다.

# 연령 등급 설문

대부분 「없음」인데 **판단이 필요한 문항이 둘** 있다. 낮게 신고했다가 걸리면
반려이므로, 아래는 **안전한 쪽**으로 적었다.

| 문항 | 답 | 왜 |
|---|---|---|
| 만화/판타지 폭력 | 없음 | |
| 사실적 폭력 | 없음 | |
| 성적 콘텐츠·노출 | 없음 | |
| 욕설·저속한 유머 | 없음 | |
| **공포·전율 소재** | **드묾/약함** | 오프닝이 비 오는 폐허 사무실이고 「눈을 떴을 때 나는 이미 채용되어 있었다」로 시작한다. 무섭게 만들 의도는 없지만 분위기는 어둡다 |
| **술·담배·마약 또는 그 언급** | **드묾/약함** | 캣닢과 「냥찰청」 압수수색 패러디가 있다. 캣닢은 고양이 장난감이지만 **틀 자체가 단속 패러디**다 |
| 모의 도박 | 없음 | 상자 뽑기는 애플 기준의 모의 도박(카지노류)이 아니다. 확률형 아이템은 별도로 게임 안에 공시한다 |
| 콘테스트 | 없음 | |
| 제한 없는 웹 접근 | **없음** | 유튜브 기능을 **앱에서 뺐다**(TODO 79). 웹판에만 있다 |

두 「드묾/약함」 때문에 등급이 4+ 가 아니라 **12+ 쯤으로 올라간다.** 낮추고 싶으면
소재를 빼야 하는 문제라, 지금은 정직한 쪽을 택했다.

# 심사 메모 (App Review Notes)

심사자가 막히는 자리를 미리 적는다. 이 칸이 비어 있으면 반려가 한 번 더 돈다.

```
로그인 없이 모든 기능을 쓸 수 있습니다. 데모 계정이 필요하지 않습니다.
앱을 켜면 익명 계정이 자동으로 만들어지고, 사무실이 바로 시작됩니다.

[게임 시계]
게임 속 시간은 기기 시계를 따릅니다. 밤에 실행하면 사무실도 밤입니다.
근무 시간은 설정에서 바꿀 수 있습니다.

[인앱 구입]
"본사 택배" 화면에서 상자를 삽니다. 상자는 소모품입니다.
· 확률은 구매 전에 "확률 정보"에서 볼 수 있습니다(서버 값을 그대로 표시합니다)
· "결제 전에 읽어 주세요"에 소모품·환불 경로·미성년자 안내가 있습니다
· "구매 복원"이 같은 화면에 있습니다
상자는 게임이 아니라 서버가 지급합니다(RevenueCat 웹훅 → 서버). 결제 직후
몇 초 지연될 수 있으며, 화면이 "곧 도착합니다"로 안내합니다.

[계정 삭제]
설정 → 계정 → "계정 삭제"에서 앱 안에서 바로 지웁니다.
안내 문서: https://copycat.sarl/delete.html

[한국어가 기본입니다]
영어와 일본어도 지원하며 기기 언어를 따릅니다.
```
