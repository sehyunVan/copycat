# copycat/site — 판매 페이지

게임 본편(`../index.html`)을 파는 랜딩페이지와, 실제로 파는 데 필요한 절차 문서.

| 파일 | 무엇 |
|---|---|
| `index.html` | 판매 랜딩페이지 + PayPal 결제 UI. 정적 파일 하나 |
| `SELLING.md` | 스토어 개설 → 배포 → 등급분류 → 세금까지의 순서 |
| `pay/` | PayPal 직접 결제 백엔드 (Cloudflare Worker). 설정법은 `pay/README.md` |
| `shot.mjs` | CDP 렌더 검증 도구 — 기기 폭을 강제해 오버플로를 측정한다 |

결제를 설정하지 않으면 페이지는 **조용히 itch.io 버튼으로 폴백한다.** 빈 자리도, 같은 버튼
두 개도 남기지 않고, 약관 문구까지 "itch.io가 처리합니다"로 바뀐다.

## 로컬에서 보기

`index.html` 더블클릭. 본편과 같은 원칙 — 빌드도 서버도 없다.

## 디자인

게임 `../style.css` 의 토큰(`--cream` `--accent` `--mint` 3px 테두리 + 오프셋 그림자)을
그대로 계승해서, 페이지와 게임이 같은 물건으로 읽히게 했다. 게임 자체가 디자인 시스템이므로
판매 페이지가 다른 톤을 쓸 이유가 없다.

- **히어로의 시계는 진짜로 돈다.** 09–18 근무 · 12–13 점심 · 22시 취침 권고 —
  게임 `js/care.js` 와 같은 규칙으로 지금 시각을 읽고 점심·퇴근까지 남은 시간을 센다.
  이 게임의 핵심 주장이 "시계를 감지 않는다"이므로, 그걸 스크린샷으로 설명하는 대신
  페이지에서 직접 돌린다.
- **고양이는 실제 게임 스프라이트다.** `assets/cats_16bit/` 시트를 data URI로 인라인해서
  CSS `steps()` 애니메이션으로 돌린다(대기 3프레임 · 앉기 2프레임 · 취침 3프레임).
  네트워크 요청이 0이라 어디에 올려도 깨지지 않는다.
- 색조 회전은 오렌지 시트 `+15deg`(버터스카치) 하나만 쓴다. 갈색 시트에 걸면 자주색이,
  폭을 넓히면 초록 고양이가 나온다 — 본편이 겪은 것과 같은 문제다.
- 다크/라이트 양쪽을 토큰 레벨에서 정의한다. `prefers-color-scheme` 과
  `[data-theme]` 이 둘 다 먹는다. 브랜드 로고만 테마와 무관하게 고정 — 로고가 테마마다
  다르면 로고가 아니다.

## 출시 전 반드시

1. ~~유료 타일셋 재배포 문제~~ → **해결됨.** 게임은 이제 원본 시트를 안 읽고
   `tools/build-atlas.js` 가 만든 전용 아틀라스(103칸·10KB)만 읽는다. 배포본은
   `node tools/pack-release.js --light-audio` 로 만든다. 자세한 건 `SELLING.md` 0단계.
2. `index.html` 의 `TODO` 주석(히어로 데모 링크, itch.io 버튼)을 실제 주소로 교체한다.
3. **가격은 세 곳에 있다** — 히어로 CTA(`$4.99에 데려가기`), 구매 박스(`$4.99`),
   그리고 `pay/worker.js` 의 `PRODUCTS`. **서버가 유일한 진짜 원본이고** 앞의 둘은
   표시용 문자열이다. 바꿀 때 셋을 같이 바꿔야 한다.
4. 청구 통화는 **USD** 다. PayPal이 KRW를 거래 통화로 지원하지 않는다.

## 검증

`node shot.mjs` 방식으로 CDP 기기 에뮬레이션을 걸어 360 / 390 / 768 / 1280px 에서
가로 오버플로 0, 다크·라이트 양쪽 렌더를 확인했다. 헤드리스 Chrome은 창 폭을 497px
아래로 안 내려가므로 `--window-size` 만으로는 모바일 검증이 안 된다 — 스크린샷이
잘린 것을 레이아웃 깨짐으로 오독하게 된다. `Emulation.setDeviceMetricsOverride` 를 써야 한다.

## 다음에 뭘 붙일 수 있나

- **플레이 가능한 데모를 페이지에 임베드** — 지금은 시계만 돈다. 첫 사무실을 iframe으로
  올리면 "설치 없이 바로 돈다"를 말하지 않고 증명할 수 있다
- **결산 리포트 카드** — 본편의 분기 보고서를 이미지로 뽑는 기능이 생기면 그게 곧 공유 자산이 된다
- **가격 A/B** — itch.io는 "$X or more" 를 지원한다. 하한만 두고 실제 지불액 분포를 보는 게
  이 게임 성격에 맞는 실험이다
- **영문 · 일본어 페이지** — 게임은 이미 3개 국어다. 페이지만 한국어인 건 판매 채널을 1/3로 줄이는 것
