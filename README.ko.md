# Copycat

> Copycat은 **고양이들이 운영하는 마약 제조·유통 조직**이다. 품목은 캣닢.
> 할 일을 끝내면 사업이 커지고, 서류를 흘리고 다니면 냥찰이 온다.

투두리스트 × 방치형 경영 시뮬 × 멀티에이전트 샌드박스.
브라우저에서 `index.html` 을 열면 바로 돌아간다. 빌드도 서버도 없다
(사무실 타일셋만 구매 에셋이라 별도 설치가 필요하다 — 설치 절 참고).

## 이 프로젝트가 던지는 질문

**"할 일 완료"를 게임의 점수가 아니라 시뮬레이션의 입력으로 넣으면 어떻게 되는가?**

보통의 게이미피케이션 투두앱은 체크 → 포인트 +10 이다. 여기서는 체크가
**월드에 물리적 사건을 발생시킨다.** 서류 한 장이 사무실 결재함에 떨어지고,
그걸 본 고양이가 자기 판단으로 걸어와서 물고 가고, 자기 자리에 앉아 도장을 찍어야
비로소 보상이 들어온다. 고양이가 전부 화장실에 가 있으면 서류는 그냥 쌓인다.

그리고 반대 방향도 만들었다. **안 한 일도 월드에 사건을 만든다.**
캣닢은 냥법상 마약류다. 이 회사는 그걸 재배하고 정제해서 유통한다. 등기부상 업종은
허브 유통업이고, 그 서류 한 장이 유일한 방패다. 그래서 분기 마감까지 정리 못 한 서류는
그냥 남아 있는 게 아니라 **밖으로 새고, 증거가 된다.** 혐의가 쌓이고, 한계를 넘기면
영장이 나오고 냥찰이 들이닥친다. 직원이 연행되기도 한다.

혐의는 돈으로 지울 수도 있다. 이 회사가 딱 그런 회사이기 때문이다.

그리고 가만히 있는 것도 중립이 아니다. 노는 사이에 경쟁 조직이 거래처를 가져간다.

성취만 보상하는 게 아니라 **미달성이 관료제를 통해 되돌아오는** 구조다.
웃긴 지점은 그게 은근히 현실적이라는 데 있다.

## 무엇이 들어있나

### 1. 자율 에이전트로서의 고양이
[OpenMMO](https://github.com/Julian-adv/OpenMMO)의 **agent–human parity**
("에이전트와 사람이 똑같은 프로토콜을 쓴다, 특권 API는 없다")를 사무실 규모로 가져왔다.

- 고양이는 **기력 / 재미 / 화장실 / 카페인** 욕구를 갖고, 스스로 시설을 찾아간다
- 플레이어의 결재도, 고양이의 낮잠도, 법무팀 방문도, 압수수색도 전부 같은 이벤트 버스(`bus`)를 지난다
- 고양이가 **자리에 앉아 있을 때만** 멸치를 번다 → 커피 마시러 가면 매출이 실제로 떨어진다
- 길찾기는 BFS. 법무팀도 냥찰도 멍멍파 끄나풀도 같은 `goTo()`를 쓴다. 벽을 통과하는 NPC는 없다

### 2. D&D식 채용
역시 OpenMMO에서: 입사할 때 **4d6 중 최저 1개를 버려서** 6능력치를 굴린다.

| 능력치 | 사무실에서의 의미 |
|---|---|
| 근성(STR) | 서류를 많이 든다 |
| 민첩(DEX) | 사무실을 빨리 돈다 |
| 체력(CON) | 덜 지친다 |
| 기획(INT) | 생산량의 핵심 |
| 눈치(WIS) | 욕구를 늦게 느낀다 (참을성) |
| 애교(CHA) | 동료 전체 생산을 올린다 |

장비 3슬롯(머리/목/발)으로 보정 가능. 분기 결산에서 드랍된다.
**능력치에만 반영되고 겉모습은 안 바뀐다** — 이유는 도트 그래픽 절에.

### 3. 절차적으로 생성되는 사무실

분기가 특정 지점(3·6·10·15·21·28)에 닿으면 사무실을 이전하고 **평면도를 새로 생성한다.**
12×10 자리 2석에서 26×22 자리 20석까지 커진다. 방은 정사각형에 가깝게 잡는데,
뷰포트가 가로로 길어서 가로로 긴 사무실은 가로가 먼저 꽉 차고 위아래에 검은 여백만 남기 때문이다.

- 구석에 **휴게실**을 칸막이로 분리한다. 벽과 출입구와 다른 바닥재를 갖고,
  커피·급식기·정수기가 그 안에 들어간다
- 책상은 **가로 2칸에 2인용**, pod 단위로 여러 행에 배치 —
  타일셋 제작자의 예시 사무실이 그렇게 되어 있다
- 가구에 **분류**가 있다. 탕비 물건은 휴게실로, 설비는 한쪽 벽을 골라 줄지어 서고,
  회의 테이블은 열린 바닥을, 화분·책장은 아무 데나. 이게 없으면 사무실이 아니라 창고로 읽힌다
- 2×2 이상은 **벽에 붙인다.** 통로 한가운데 선 자판기는 사무실로 안 보인다
- 액자·화이트보드는 **벽에 건다.** 격자와 별도로 관리해서 길찾기에 영향이 없다
- **모든 배치는 연결성 검사를 통과해야 한다** — 바닥을 끊거나, 이미 놓인 물건의 진입로를
  막으면 되돌린다. 안 하면 고양이가 구석에 갇힌다. 실제로 갇혔었다
- 전수 검증: 7티어 × 30시드 = 210개 평면도, 도달 불가 자리 0, 누락 시설 0, 통로에 선 큰 가구 0

**배치는 저장된다. 다시 유도하지 않는다.** 예전엔 비품을 사면 사무실을 통째로 재생성해서
기존 가구가 전부 이사했고, 게임을 다시 켜도 마찬가지였다. 평면도가 저장이 아니라
`시드 + 보유 비품`에서 매번 유도됐기 때문이다. 이제 격자를 저장해 그대로 되살린다.
생성은 **창업할 때와 이전할 때 딱 두 번.** 비품을 사면 그 가구 하나만 끼워 넣는다.

### 4. 혐의 · 법무 · 냥찰

| 상황 | 결과 |
|---|---|
| 전 분기 이월 미처리 건 | 밖으로 샌다 · 건당 혐의 1점(큰 건 2점) · 뒷수습 비용 |
| 혐의 누적 | 1점당 전 직원 생산 −6% — 다들 몸을 사린다 |
| 흔적 없이 넘긴 분기 | 혐의 1점 소멸 |
| 무마 (법무법인) | 혐의 1점을 지운다. 보유 멸치의 22% — 회사가 클수록 비싸다 |
| 혐의 5점 초과 | 🚨 영장 발부, 압수수색 (조사 중 생산 40%) |
| 압수수색 종료 | 과징금 15% · 혐의 0 초기화 · 35% 확률로 직원 1명 연행 |
| 연행된 직원 | 다음 분기 결산에 무혐의 복귀. 아무 말도 안 했다고 한다 |

유예가 한 분기 있다. 오늘 올린 일이 오늘 마감에 걸리지는 않는다.

오는 경찰은 늘 **도 경찰과 김 경찰** 둘이다. 매번 다른 조합이 나오면 조직이 아니라
무작위 NPC로 읽힌다.

진짜 긴장은 혐의 게이지에 있다. 무사고 분기로 버틸 수도 있고, 그냥 돈으로 막을 수도 있다.
돈이 빠르다. 그리고 그건 명백히 뇌물이다.

### 5. 경쟁사 — 멍멍파

마약 개껌을 만드는 강아지 조직. 문구가 아니라 시스템이다.

분기마다 처리 건수를 **사무실 규모에 비례하는 기준치**와 비교한다(첫 사무실 3건 → 마지막 15건).
못 미치면 거래처를 뺏기고 **점유율만큼 전 직원 생산이 깎인다**(상한 60%). 넘기면 되찾는데,
잃는 속도보다 되찾는 속도가 느리다.

3분기 방치하면 생산이 54%까지 떨어진다. 점유율이 25%를 넘으면 그쪽 끄나풀이
문 앞에 나타나 어슬렁거리다 간다. 분기 결산에는 점유율에 따라 수위가 올라가는
「멍멍파 근황」이 붙는다 — *"아직 우리 구역 밖에 있습니다"* 부터
*"거래처 절반이 개껌을 같이 받고 있습니다. 곧 우리를 뺄 겁니다"* 까지.

**이게 게임에 없던 조각이다.** 전까지는 가만히 있으면 그냥 안 벌 뿐이었는데,
이제 가만히 있으면 손해다.

### 6. 도트 그래픽 — 출처가 셋이다

**고양이는 [16-bit Kitties](https://mxmaze.itch.io/16-bit-kitties-pack)**
(Maze.Bit.Boutique, **CC BY 4.0**). 16×16, 색상당 9프레임. 시트의 행 구성이 우리 상태에
거의 그대로 맞았다 — 서 있기는 대기·이동, 앉기는 책상 앞 근무, 눕기는 취침.
자리에 도착하면 실제로 앉는다.

4색으로는 직원 20마리를 구분할 수 없다. 그렇다고 캔버스로 색을 바꿀 수도 없다 —
`file://` 에서 외부 이미지를 캔버스에 그리면 오염돼 `toDataURL()`이 막힌다.
그래서 **CSS `hue-rotate`** 로 고양이마다 색조를 돌린다. 캔버스가 아예 필요 없다.
4시트 × 8회전 = 구분되는 외형 24종. 회전 폭은 초록 고양이가 안 나오게 좁혔고,
검정은 화면에서 존재감이 커서 확률을 25%→11%로 낮췄다.

원래는 ASCII 맵으로 직접 그린 고양이였다. 그 버전은 악세서리·장비를 팔레트 오버레이로
합성했는데 고정된 시트로는 안 된다 — **장비는 이제 능력치에만 반영된다.**
분명한 손실이고, 고양이가 고양이처럼 보이는 것과 맞바꿨다.

**가구·바닥·벽은
[LimeZu Modern Office - Revamped](https://limezu.itch.io/modernoffice)** (16×16, 유료).
같은 오염 문제 때문에 캔버스가 아니라 CSS `background-position`으로 잘라 쓴다.
이 팩은 가구가 여러 칸에 걸쳐 있어서 "물건 하나 = 한 칸" 격자와 충돌한다. 그래서
`tall`·`wide` 를 붙였다 — 위/옆 칸까지 넘겨 그리되 생성기가 그 칸을 예약하고,
길찾기는 여전히 한 칸만 막힌 것으로 본다. 가구도 고양이와 같은 축으로 깊이를 매겨서,
책상 뒤를 지나는 고양이는 가려지고 앞자리에 앉은 고양이는 안 가려진다.

책상에는 모니터·서류·스탠드를 한 겹 더 얹는다(타일 좌표로 골라서 같은 자리는 늘 같은 물건).
화면 전체에는 따듯한 곱하기 오버레이를 깐다 — 타일셋 바닥이 차가운 회색이라
크림색 UI와 딴 게임처럼 놀기 때문이다.

**개는 코드로 그렸다.** 산 팩에 개가 없어서, 나머지와 같은 16×16 격자로.
팩에 대응물이 없는 물건 몇 개도 마찬가지다.

타일 좌표는 전부 **눈대중이 아니라 측정**해서 골랐다 — 아래 `tools/sprite-audit.js` 참고.
효과음은 WebAudio 합성이라 오디오 파일이 없다.

## 그래픽 에셋 설치

가구·바닥 타일셋은 **[Modern Office - Revamped](https://limezu.itch.io/modernoffice) (LimeZu)**
유료 에셋이다. 라이선스가 상업 이용은 허용하지만 **에셋 자체의 재배포는 금지**하므로
저장소에 넣지 않고 `.gitignore` 로 제외했다. 새로 클론하면 게임은 돌지만 사무실이 비어 보인다.

구매한 뒤 아래 파일을 `assets/modern_office/` 에 복사한다:

```
assets/modern_office/
├── Modern_Office_Shadowless_16x16.png    # 3_Modern_Office_Shadowless/ 에서
├── Room_Builder_Office_16x16.png         # 1_Room_Builder_Office/ 에서
└── LICENSE.txt                           # 팩 최상위에서
```

고양이 시트는 CC BY라 저장소에 이미 들어 있다. 소리와 코드로 그린 물건은 설치할 게 없다.

## 검증

세 겹이다. 각 겹이 앞 겹이 놓친 걸 잡았기 때문이다.

**헤드리스 하네스**는 DOM 없이 코어 파일만 로드해 시뮬레이션을 직접 돌린다 —
결재 파이프라인 / 10분 구동 안정성 / 법무 이관 / 무마 / 압수수색·연행·복귀 /
경쟁사 점유율 변동 / 사무실 이전 / 저장·복원 / 210개 평면도 도달 가능성.

그것만으로는 부족하다 — **고양이 절반이 화면에서 안 보이는 상태로도 전부 통과했다.**
그래서 **실제 헤드리스 Chrome을 CDP로 조작**한다. 부팅 → 모달 닫기 → 할 일 등록 →
체크 → 고양이가 서류 운반하는지 확인 → 압수수색 발동 → 인사 기록 열기, 각 단계를 스크린샷으로.

둘 다 **스프라이트가 애초에 잘못된 크기인 것**은 못 잡는다. 그래서
**`tools/sprite-audit.js`** 가 타일셋의 알파 채널을 디코딩하고, 게임이 참조하는 모든 타일에서
flood fill로 실제 경계를 뽑아 보고한다. "가구 몇 개가 잘려 보인다"를 **기준칸·크기가 틀린
18개의 정확한 목록**으로 바꿔줬다. 지금은 0건이고, 새 타일을 고를 때는 추측 말고 이걸 돌리면 된다.
