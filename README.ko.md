# Copycat

> 고양이들이 사무직을 한다. 당신이 할 일을 끝내면 회사가 커지고,
> 안 끝내면 법무팀이 온다.

투두리스트 × 방치형 경영 시뮬 × 멀티에이전트 샌드박스.
브라우저에서 `index.html` 을 열면 바로 돌아간다. 빌드도, 서버도, 설치할 의존성도 없다.

## 이 프로젝트가 던지는 질문

**"할 일 완료"를 게임의 점수가 아니라 시뮬레이션의 입력으로 넣으면 어떻게 되는가?**

보통의 게이미피케이션 투두앱은 체크 → 포인트 +10 이다. 여기서는 체크가
**월드에 물리적 사건을 발생시킨다.** 서류 한 장이 사무실 결재함에 떨어지고,
그걸 본 고양이가 자기 판단으로 걸어와서 물고 가고, 자기 자리에 앉아 도장을 찍어야
비로소 보상이 들어온다. 고양이가 전부 화장실에 가 있으면 서류는 그냥 쌓인다.

그리고 반대 방향도 만들었다. **안 한 일도 월드에 사건을 만든다.**
분기 마감 시점에 전 분기 이월 미처리 건은 법무팀으로 이관되고, 벌점이 쌓이고,
한계를 넘기면 냥찰청 특별사법경찰이 압수수색을 나온다. 직원이 연행되기도 한다.
성취만 보상하는 게 아니라 **미달성이 관료제를 통해 되돌아오는** 구조다.
웃긴 지점은 그게 은근히 현실적이라는 데 있다.

## 무엇이 들어있나

### 1. 자율 에이전트로서의 고양이
[OpenMMO](https://github.com/Julian-adv/OpenMMO)의 **agent–human parity**
("에이전트와 사람이 똑같은 프로토콜을 쓴다, 특권 API는 없다")를 사무실 규모로 가져왔다.

- 고양이는 **기력 / 재미 / 화장실 / 카페인** 욕구를 갖고, 스스로 시설을 찾아간다
- 플레이어의 결재도, 고양이의 낮잠도, 법무팀의 방문도 전부 같은 이벤트 버스(`bus`)를 지난다
- 고양이가 **자리에 앉아 있을 때만** 멸치를 번다 → 커피 마시러 가면 매출이 실제로 떨어진다
- 길찾기는 BFS. 법무팀도 냥찰도 같은 `goTo()`를 쓴다. 벽을 통과하는 NPC는 없다

### 2. D&D식 채용
역시 OpenMMO에서: 입사할 때 **4d6 중 최저 1개를 버려서** 6능력치를 굴린다.

| 능력치 | 사무실에서의 의미 |
|---|---|
| 근성(STR) | 서류를 많이 든다 |
| 민첩(DEX) | 사무실을 빨리 돈다 |
| 체력(CON) | 덜 지친다 |
| 기획(INT) | 생산량의 핵심 |
| 눈치(WIS) | 욕구를 늦게 느낀다 (참을성) |
| 애교(CHA) | 동료 전체 생산을 올린다 |

장비 3슬롯(머리/목/발)으로 보정 가능. 장비는 분기 결산에서 드랍된다.

### 3. 절차적으로 생성되는 사무실
분기가 특정 지점(3·6·10·15·21·28)에 닿으면 사무실을 이전하고,
**평면도를 매번 새로 생성한다.** 시드 기반이라 저장/복원해도 같은 배치가 나온다.

- 책상은 2칸짜리 팀 pod 단위로 여러 행에 분산
- 비품은 사면 실제 타일로 배치되고 고양이가 그걸 이용한다 (커피머신을 사야 카페인 욕구가 생긴다)
- **모든 배치는 연결성 검사를 통과해야 확정된다** — 무언가를 놓아서 바닥이 끊기면 되돌린다
  (안 하면 고양이가 구석에 갇힌다. 실제로 갇혔었다)
- 7티어 × 30시드 = 210개 평면도 전수 검증: 도달 불가 자리 0

### 4. 법무팀 · 냥찰
| 상황 | 결과 |
|---|---|
| 전 분기 이월 미처리 건 | 법무팀 이관 · 건당 벌점 1점(큰 건 2점) · 법무 비용 청구 |
| 벌점 누적 | 벌점 1점당 전 직원 생산 −6% |
| 무사고 분기 | 벌점 1점 소멸 |
| 벌점 5점 초과 | 🚨 냥찰청 압수수색 (조사 중 생산 40%) |
| 압수수색 종료 | 과징금 15% · 벌점 0 초기화 · 35% 확률로 직원 1명 연행 |
| 연행된 직원 | 다음 분기 결산에 무혐의 복귀 |

유예가 한 분기 있다. 오늘 올린 일이 오늘 마감에 걸리지는 않는다.

### 5. 도트 그래픽 — 출처가 두 개다

**고양이는 코드가 런타임에 생성한다.** 스프라이트 파일이 없다. ASCII 맵을 캔버스에 찍어
dataURL로 캐시한다.

```js
const CAT_IDLE = [
  '.oo......oo...',
  'oppo....oppo..',
  'obbbbbbbbbbo..',
  ...
];
```

털색·악세서리·장비가 팔레트 오버레이로 합성되므로 조합이 늘어도 파일이 안 는다.
직원 20마리가 전부 달라 보여야 하는데, 이건 에셋 팩으로는 안 되는 일이다.

**가구는 타일셋을 쓴다.** [Kenney의 Roguelike Indoors](https://kenney.nl/assets/roguelike-indoors)
(16×16, **CC0 / 퍼블릭 도메인**)를 CSS `background-position`으로 잘라 쓴다.
캔버스를 안 쓰는 이유가 있다 — `file://` 에서 외부 이미지를 캔버스에 그리면 캔버스가
오염돼 `toDataURL()`이 막힌다. 시트에 대응물이 없는 물건(결재함·서버룸·로켓·낮잠 상자)은
여전히 코드로 그리고, 두 방식이 하나의 `FURN` 테이블에 공존한다. 이 팩엔 바닥·벽 타일이
없어서 그 둘은 CSS로 남겨뒀다.

기능 없는 순수 장식(액자·선반·화분)도 생성기가 등급에 비례해 흩뿌린다.
이게 없으면 초반 사무실이 텅 빈 방으로 읽힌다.

크기는 의도적이다. 가구는 타일 한 칸을 꽉 채우고(16논리 → 32px), 고양이는 그보다 작다
(14×13 → 28×26). 픽셀 밀도는 전부 동일해서 리샘플된 것처럼 보이지 않는다.

효과음은 WebAudio 신디사이즈 — 오디오 파일 없음.

### 6. 그 밖에
- 낮/밤 사이클 (하루 32분): 09–18 근무, 18–22 야근(야근형만), 22시 이후 취침
- 오프라인 수익 최대 8시간(자동급식기 16시간)
- 9개 특성(야근형·낮잠형·행운냥·커피중독…), 8단계 직급, 10종 비품, 16종 분기 이벤트
- localStorage 자동 저장

## 파일 구조

```
copycat/
├── index.html          # 마크업
├── style.css           # 도트 톤 UI
├── assets/
│   └── kenney_roguelike-indoors/   # CC0 가구 타일셋 + 라이선스 원문
└── js/
    ├── world.js        # 절차적 평면도 생성 + BFS 길찾기
    ├── cats.js         # 고양이 데이터 · 4d6 능력치 · 특성 · 장비
    ├── sprite.js       # ASCII 맵 → 캔버스 도트 스프라이트
    ├── sim.js          # 20Hz 시뮬레이션 · 에이전트 상태기계 · 이벤트 버스 · NPC
    ├── game.js         # 경제 · 결재함 · 분기 · 법무/냥찰 · 저장
    ├── ui.js           # 렌더링 · 모달
    └── main.js         # 부팅 · 루프 · 입력
```

## 실행

`index.html` 더블클릭. 끝. (`file://` 에서 그대로 동작한다)

## 검증

두 겹이다. **헤드리스 하네스**는 DOM 없이 코어 파일만 로드해 시뮬레이션을 직접 돌린다 —
결재 파이프라인 / 10분 구동 안정성 / 법무 이관 / 압수수색·연행·복귀 / 사무실 이전 /
저장·복원 / 210개 평면도 도달 가능성.

그것만으로는 부족하다 — 고양이 절반이 화면에서 안 보이는 상태로도 전부 통과했다.
그래서 **실제 헤드리스 Chrome을 CDP로 조작**한다. 부팅 → 모달 닫기 → 할 일 등록 →
체크 → 고양이가 서류 운반하는지 확인 → 압수수색 발동, 각 단계를 스크린샷으로 남긴다.
그림은 스프라이트 시트를 PNG로 뽑아서(의존성 없는 자체 인코더) 눈으로 검수한다.

## 다음에 뭘 붙일 수 있나

- **고양이끼리의 관계** — 사교 시설에서 마주친 횟수로 친밀도가 쌓이고,
  친한 고양이 옆자리면 생산 +, 사이 나쁘면 −. 사내 정치.
- **진짜 LLM 에이전트** — 지금 고양이는 유틸리티 AI다. 여기에 LLM을 물려서
  사보에 실릴 사내 루머를 스스로 쓰게 하면? agent–human parity의 원래 의도에 더 가까워진다.
- **경쟁사 멍멍상사** — 같은 규칙으로 도는 AI 회사. 분기마다 매출 비교.
- **노동조합** — 사기가 계속 낮으면 파업. 협상 미니게임.
- **실제 캘린더/이슈트래커 연동** — GitHub 이슈나 Todoist를 결재함으로. 진짜 업무가 입력이 된다.
- **결산 리포트 이미지 내보내기** — 분기 보고서를 카드 이미지로 저장/공유
- **감사(Audit) 모드** — 법무팀이 특정 서류의 처리 이력을 추적. 어느 고양이가 언제 도장 찍었는지 로그.
- **멀티플레이** — OpenMMO처럼 WebSocket으로 여러 사람의 사무실을 한 건물에
